Program Website Widget — live demo

This page shows the embeddable widget rendering a real program's public listings. Paste the snippet below into any website to show your own.

Live widget
The embed code
<div id="t4u-widget"></div>
<script src="https://theatre4u.org/widget.js"
        data-org="your-program-slug"
        data-target="t4u-widget"
        data-limit="12"></script>

Replace your-program-slug with the slug from My Profile → Public Profile URL. ArtsTracker programs use https://artstracker.org/widget.js.
